# Android Txt阅读器

我要做一个txt小说阅读器的Android应用

## 技术栈

语言：Android Koltin

框架：Jetpack Compose

数据库：SQLite

## 功能需求

- 可将txt文件的默认打开应用设置该应用
- 初次进入APP时检查并获取文件读取权限
  **小说卡片列表**
- 小说卡片列表，显示名字和进度（当前章节/章节总数），右上角有添加txt文件的按钮（txt文件多选），排序切换按钮（时间、名称、文件大小进行升序或降序排序，默认按时间降序排序）
- 点击设置按钮，多选勾选txt文件卡片，可进行批量删除记录或批量删除文件，删除记录及删除该条阅读记录，删除文件即删除改txt文件
- 顶部搜索栏，按照关键词过滤出符合的txt文件

**txt阅读界面**

- 点卡小说卡片列表的卡片，进入阅读界面
- 顶部有返回按钮，显示txt文件名称，进度（当前章节/章节总数）
- 阅读内容区，根据内容区高度计算出每行字数，每页的行数，再进行章节页的划分，加载到显示某章节某分页内容，左右滑动切换下一页，
- 下方工具栏：
  - 章节列表点击，切换到该章节
  - 语音朗读配置，播放与暂停按钮，上一页下一页按钮，上一章与下一章按钮，播放速度滑动条
  - 播放按钮，用于切换播放与暂停
  - 搜索界面，搜索txt内容关键词，把包含关键词的文本结果列表，高亮关键词文本，点击后可快速跳转到该章节和分页
  - 阅读设置界面，可配置字体大小（默认16px），行高（默认2倍行高），字体颜色，背景颜色，章节正则匹配规则（下拉选择），编码方式(可选：GBK，UTF-8，默认UTF8)
  - 朗读时，播放栏出现在通知栏，方便控制

**存储在SQLite的阅读记录字段如下**

```txt
{
  /**当前章节 */
  currentChapter: number;
  /**当前章节页*/
  pageIndex: number;
  /**章节数量*/
  totalChapter: number;
  /**字数*/
  textNum: number;
  /**更新时间*/
  updateTime: number;
  /**文件路径*/
  filePath: string;
  /** 文件名称*/
  fileName: string;
  /**文件大小*/
  fileSize: number;
  /**章节正则类型*/
  regexType: number;
  /**章节正则表达式*/
  regexStr: string;
  /**编码方式*/
  encodeStr: string;
}
```
